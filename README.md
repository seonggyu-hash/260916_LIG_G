# 🧬 LIG DNA Smart Task Manager

LIG DNA 핵심가치(**도전·신뢰·첨단·혁신**)를 기반으로 제작된 프리미엄 스마트 할 일(Task/Todo) 관리 웹 애플리케이션입니다.  
Python Flask 백엔드와 세련된 글래스모피즘(Glassmorphism) 다크/라이트 UI가 결합되어 최상의 사용자 경험을 제공합니다.

---

## ✨ 핵심 기능 소개

1. **LIG DNA 핵심가치 매트릭스 & 대시보드**
   - **도전(Challenge) / 신뢰(Trust) / 첨단(Tech) / 혁신(Innovation)** 가치 태그별 현황 및 실시간 KPI 카운터
   - 전체 업무량, 실시간 완료율(%), 긴급(Critical) 과제 현황 게이지 시각화
   - DNA 가치 뱃지 클릭 시 해당 핵심가치 업무만 원클릭 필터링

2. **직관적인 스마트 할 일 관리 (CRUD)**
   - 업무명, 카테고리(개발, 기획, 협업, 연구, 일반업무), DNA 태그, 우선순위(긴급/높음/보통/낮음), 마감일자, 상세 메모
   - 완료 토글 시 Web Audio API 기반의 청명한 효과음(Chime) 및 실시간 스트라이크스루 애니메이션
   - 수정(Modal) 및 삭제 기능, 완료된 항목 일괄 정리(Batch Clean) 기능

3. **실시간 검색 및 다차원 필터링**
   - 업무명 및 메모 통합 실시간 디바운스 검색
   - 진행 상태별(전체/진행중/완료), 우선순위별, 카테고리별 필터
   - 정렬 옵션: 최신순, 오래된순, 마감임박순, 중요도순

4. **엑셀 호환 CSV 데이터 내보내기 (Export)**
   - 한글 깨짐 방지 UTF-8 BOM 인코딩이 적용된 CSV 파일 즉시 다운로드

5. **프리미엄 반응형 UI & 단축키**
   - 사이버 슬레이트 딥 다크 모드 & 클린 라이트 모드 실시간 전환 (설정 자동 저장)
   - 실시간 시계 위젯 (날짜 및 요일 표시)
   - 키보드 단축키 지원:
     - `N`: 새 업무 등록 창 열기
     - `/`: 검색창 바로 포커스
     - `ESC`: 모달 창 닫기

## 📁 디렉터리 구조

```
│   └── index.html         # 메인 웹 페이지 템플릿
└── static/
    ├── css/
    │   └── style.css      # 디자인 시스템, 글래스모피즘, 애니메이션
    └── js/
        └── app.js         # 리액티브 UI 제어, Web Audio 사운드 합성, API 통신
```

## 🚀 실행 방법

### 방법 1. 간편 실행 (가장 추천)
폴더 내의 **`run.bat`** 파일을 더블 클릭하면 자동으로 의존성을 확인하고 웹 브라우저(`http://127.0.0.1:5000`)를 열어줍니다.

### 방법 2. 터미널 수동 실행
```powershell
# 1. LIG_DNA_TODO_APP 폴더로 이동
cd LIG_DNA_TODO_APP

# 2. 필수 라이브러리 설치
python -m pip install -r requirements.txt

# 3. 서버 실행
python app.py
```
실행 후 웹 브라우저에서 **`http://127.0.0.1:5000`** 에 접속하시면 바로 사용하실 수 있습니다.
